# Sentinel Workspace – OFFLINE WWW #2

Kompletna statyczna witryna drugiego systemu cyfrowego gry OFFLINE.

## Uruchomienie
1. Rozpakuj archiwum ZIP.
2. Otwórz `index.html` w aktualnej przeglądarce.
3. Strona działa lokalnie, bez serwera i internetu.

## Dane dostępu do archiwum
- Lokalizacja: `DC03`
- Autor: `AK`
- Wersja: `1.0`

## Najważniejsze funkcje
- pełny interfejs PL/EN,
- brama odzyskania archiwum,
- dashboard firmowego workspace,
- biblioteka dokumentów i foldery,
- `sandbox_old` i wyróżniony `RECOVERED_MAIN_LOG.txt`,
- filtrowalne logi DC03,
- zdjęcia plomb B-1193 i C-4421,
- rejestr tokenów z SEC-04,
- wyszukiwanie zadania wydruku 44318,
- historia wersji notatki o spotkaniu,
- archiwum konferencji i transkrypcja,
- szczegóły Virtual Camera / Virtual Audio Cable,
- `test_call_final.mp4`,
- odzyskany szkic wiadomości,
- wyszukiwarka globalna,
- lokalny zapis postępu i statusów przeczytania,
- trzystopniowa pomoc,
- reset sesji,
- responsywny układ.

## Publikacja
Folder można opublikować na dowolnym hostingu statycznym. Zachowaj wspólnie pliki `index.html`, `styles.css` i `app.js`.

## Uwaga produkcyjna
Galeria plomb i odtwarzacze są wykonane jako samowystarczalne makiety HTML/CSS, aby paczka działała bez zewnętrznych assetów. Można później podmienić placeholdery na docelowe fotografie oraz pliki wideo/audio bez zmiany struktury interfejsu.
